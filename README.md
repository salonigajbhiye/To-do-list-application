🌐 Task Manager

A Web Development Project developed as part of the Web Development Training Program at UNISOFT TECHNOLOGIES, Nagpur.

📌 Project Overview

Task Manager is a web-based task management application developed using HTML, CSS, and JavaScript.

The project was created to apply the concepts learned during the Web Development Training Program and to gain practical experience in designing and developing an interactive web application.

The project focuses on helping users organize their daily tasks by allowing them to add, edit, complete, and delete tasks. It also stores tasks in the browser using Local Storage, ensuring that tasks remain available even after the page is refreshed.

💡 Problem Statement

What problem does this project solve?

Managing daily tasks on paper or remembering them mentally can be inconvenient and inefficient. This project provides a simple and user-friendly task management system where users can easily create, update, complete, and remove tasks while keeping their task list saved in the browser.

💡 Project Idea

The basic idea behind this project is to create a lightweight task management application that helps users organize their daily activities efficiently.

The website is designed to provide users with an easy way to manage their tasks while maintaining a simple, responsive, and user-friendly interface. Tasks can be added, edited, marked as completed, deleted, and automatically saved using the browser's Local Storage.

🧩 Challenges Faced

During the development of this project, I faced several challenges.

Challenge 1

Problem:

Managing tasks dynamically after adding them to the page.

Solution:

Used JavaScript DOM manipulation to create and append task elements dynamically.

Challenge 2

Problem:

Keeping tasks available after refreshing the browser.

Solution:

Implemented Local Storage to save and retrieve tasks automatically.

Challenge 3

Problem:

Maintaining completed task status after page reload.

Solution:

Stored both the task text and completion status in Local Storage and restored them during page initialization.
